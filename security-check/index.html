セキュリティ診断

ボタンを押すだけで、今使っているブラウザと接続の安全性を100点満点で診断します。

-- 点

準備ができたらボタンを押してください

診断はこの端末の中だけで行い、結果や情報はどこにも送信しません。

診断結果

    このサイトから見えるあなたの情報

    どのWebサイトも、特別な許可なしに、少なくともこれくらいの情報は読み取れます。組み合わせると、あなたの端末を見分ける手がかり（指紋）になることがあります。

    診断していること

    • ブラウザが最新か：Chrome・Edge・Firefox は約4週ごと、Safari は年1回新しい版が出ます。その周期から、今日の日付で出ているはずの版を計算し、使っている版と比べます。
    • サポート中のOSか：Windows 7・8 など、セキュリティ更新が終わったOSを見つけます。
    • 暗号化された接続か：このページとの通信が HTTPS で暗号化されているかを確かめます。
    • IPアドレスが漏れていないか：ビデオ通話などに使う機能（WebRTC）から、端末のIPアドレスがサイトに見えてしまわないかを調べます。外部のサーバーには接続しません。

    よくある質問

    100点なら、ウイルスや詐欺の心配はありませんか？

    いいえ。この診断は、ブラウザとOSの「更新されているか」など、外から確かめられる基本の項目だけを見ています。怪しいリンクを開かない、パスワードを使い回さないといった習慣も大切です。リンクは怪しいURLチェック、パスワードはパスワードの強さチェックで確かめられます。

    ブラウザを更新するにはどうすればいいですか？

    Chrome・Edge は右上のメニューから「ヘルプ」→「（ブラウザ名）について」を開くと、自動で更新が始まります。iPhone の Safari は、iOS のアップデート（設定 → 一般 → ソフトウェアアップデート）で更新されます。

    点数が毎回少し変わるのはなぜ？

    ブラウザの設定や、使っているネットワークによって結果が変わることがあります。たとえば会社のネットワークやVPNを使っているときは、IPアドレスの項目が変わることがあります。

    診断は、ブラウザが自分で名乗っている情報（User-Agent）などにもとづく目安です。ブラウザの設定や拡張機能によっては、正しく判定できないことがあります。

    • IPA 情報処理推進機構「情報セキュリティ」
